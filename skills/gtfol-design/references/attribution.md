# Design engineering inspiration

The interaction and motion guidance draws on Emil Kowalski's
[design engineering skill](https://github.com/emilkowalski/skill/blob/85e8e2363b713506e1d5b6e07a0eb2da66be1bc3/skills/emil-design-eng/SKILL.md),
reviewed on 2026-09-16 at revision
`85e8e2363b713506e1d5b6e07a0eb2da66be1bc3`.

Gtfol's skill uses independently written, selective guidance adapted to Allen's
Freewrite/Capsule design standard. It does not install the upstream skill or
adopt its fixed response format, introductory response, or universal animation
rules. This is not an endorsement by the original author.
